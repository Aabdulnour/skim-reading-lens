# A 30-second Skim demo

Working hook: **ChatGPT writes a novel. I go hunting for one sentence.**

| Time | Show | Say |
| --- | --- | --- |
| 0-4 seconds | A long sample answer with emphasis off | “I realized I don't read most AI answers from top to bottom. I scan for the part I actually need.” |
| 4-11 seconds | Turn on the lens and move to a paragraph | “So I built Skim. I point at a paragraph, and it brings one original sentence forward.” |
| 11-17 seconds | Switch from The answer to The catch | “And if I want the catch, it looks for the condition I might otherwise miss.” |
| 17-23 seconds | Show the original context and a pinned sentence | “Nothing gets rewritten. The source stays here, and I can pin the part worth keeping.” |
| 23-30 seconds | Show the input controls and finish on the product | “It works with a pointer. Webcam gaze is experimental. Would you actually use this when reading a long AI response?” |

For an immediate recording, use the built-in scripted tour and keep its **Scripted demo** label visible. Say or caption that attention is simulated. For a real gaze recording, first calibrate on your own device, then film a successful session without editing out failures in a way that implies universal accuracy. Do not describe a pointer demonstration as live eye tracking.

Suggested caption:

> I made a reading lens for the way I already read AI responses: scan for the answer, then look for the catch. It keeps the original text and changes the emphasis. Pointer mode works now; webcam gaze is an experiment. Curious whether this feels useful or distracting to other people.
